## Naming Rules

1. **Aggregate Roots:** PascalCase, singular noun (e.g., `User`, not `Users`)
2. **Value Objects:** PascalCase, descriptive compound (e.g., `EmailAddress`, not `Email`)
3. **Repositories:** `{EntityName}Repository` (e.g., `UserRepository`)
4. **Use Cases:** `{Verb}{Noun}UseCase` (e.g., `RegisterUserUseCase`)
5. **Services:** `{Noun}Service` for application services, `{Noun}DomainService` for domain services
6. **Events:** Past tense `{Noun}{Verb}ed` (e.g., `UserRegistered`, `OrderPlaced`)

## Commit Message Language

Use domain terms in commit messages:
- `feat(user): add email verification` (correct)
- `feat(account): add email check` (wrong — "account" is not in our glossary, use "user")
